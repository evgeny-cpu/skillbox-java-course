## 🏦 Задача 1 & 2: Система банковских счетов

**Цель:** Освоить наследование и правильно выбрать модификаторы доступа.

### Иерархия классов

-   `BankAccount` (Базовый класс)
    -   `CardAccount` (Карточный счёт)
    -   `DepositAccount` (Депозитный счёт)

### Логика работы

| Класс | Пополнение | Снятие | Особенности |
| :--- | :--- | :--- | :--- |
| **BankAccount** | Без комиссии.<br>Отрицательное значение игнорируется. | Без комиссии.<br>Нельзя снять больше, чем есть на счёте. | Базовый счёт. |
| **CardAccount** | Наследует логику `BankAccount`. | **Комиссия 1%** (со 100 руб. спишется 101 руб.). | Переопределён метод `withdraw`. |
| **DepositAccount** | Наследует логику `BankAccount`. | Нельзя снять деньги в течение **1 месяца** после последнего пополнения. | Хранит дату последнего пополнения (`lastIncome`). |

### Модификаторы доступа (Задача 2)

-   `private`: Для внутренних переменных состояния (баланс, дата последнего пополнения).
-   `protected`: Для методов, которые должны быть доступны только наследникам (например, базовая логика снятия).
-   `public`: Для публичного API класса (методы `put`, `withdraw`, `getBalance`).

## 👥 Задача 3: Типы клиентов (Абстрактный класс)

**Цель:** Научиться использовать абстрактные классы для описания общей логики.

### Иерархия

-   `Client` (Абстрактный класс)
    -   `PhysicalPerson` (Физическое лицо)
    -   `LegalPerson` (Юридическое лицо)
    -   `IndividualBusinessman` (ИП)

### Условия операций

| Клиент | Пополнение | Снятие | Комиссия |
| :--- | :--- | :--- | :--- |
| **PhysicalPerson** | Без условий | Без условий | Нет |
| **LegalPerson** | Без условий | **Комиссия 1%** | Есть (при снятии) |
| **IndividualBusinessman** | Комиссия **1%**, если сумма < 1000 руб.<br>Комиссия **0.5%**, если сумма >= 1000 руб. | Без условий | Есть (при пополнении) |

### Методы

-   `put(double amount)` — пополнить счёт.
-   `take(double amount)` — снять средства.
-   `getBalance()` — получить баланс.
-   `printInfo()` — вывести информацию о счёте в консоль.

## 🏢 Задача 4: Компания и сотрудники (Интерфейсы)

**Цель:** Научиться работать с интерфейсами и сложным взаимодействием объектов.

### Ключевые компоненты

1.  **Интерфейс `Employee`**
    -   Метод: `getMonthSalary()` — возвращает зарплату сотрудника.

2.  **Классы сотрудников**
    -   **Operator**: Фиксированная зарплата.
    -   **Manager**: Фикс + 5% от сгенерированной выручки (115 000 – 140 000 руб.).
    -   **TopManager**: Фикс + бонус 150%, если доход компании > 10 млн руб.

3.  **Класс `Company`**
    -   `hire(Employee employee)` — нанять сотрудника.
    -   `hireAll(List<Employee> employees)` — нанять список.
    -   `fire(Employee employee)` — уволить сотрудника.
    -   `getIncome()` — получить доход компании.
    -   `getTopSalaryStaff(int count)` — топ N зарплат (по убыванию).
    -   `getLowestSalaryStaff(int count)` — низшие N зарплат (по возрастанию).

### Демонстрационный сценарий

1.  Создать компанию и нанять:
    -   180 `Operator`
    -   80 `Manager`
    -   10 `TopManager`
2.  Вывести **10–15** самых высоких зарплат.
3.  Вывести **30** самых низких зарплат.
4.  Уволить **50%** сотрудников.
5.  Повторно вывести топ и низшие зарплаты.
