## 👥 Задача 3: Типы клиентов (Абстрактный класс)

**Цель:** Научиться использовать абстрактные классы для описания общей логики.

### Иерархия

-   `Client` (Абстрактный класс)
    -   `PhysicalPerson` (Физическое лицо)
    -   `LegalPerson` (Юридическое лицо)
    -   `IndividualBusinessman` (ИП)

### Условия операций

| Клиент | Пополнение | Снятие | Комиссия |
| :--- | :--- | :--- | :--- |
| **PhysicalPerson** | Без условий | Без условий | Нет |
| **LegalPerson** | Без условий | **Комиссия 1%** | Есть (при снятии) |
| **IndividualBusinessman** | Комиссия **1%**, если сумма < 1000 руб.<br>Комиссия **0.5%**, если сумма >= 1000 руб. | Без условий | Есть (при пополнении) |

### Методы

-   `put(double amount)` — пополнить счёт.
-   `take(double amount)` — снять средства.
-   `getBalance()` — получить баланс.
-   `printInfo()` — вывести информацию о счёте в консоль.
