## 👨‍💼 Задача 1: Сортировка сотрудников (7.2 Домашняя работа 7.1)

**Цель:** Освоить лямбда-выражения для сортировки коллекций.

### Условие

Необходимо отсортировать список сотрудников **одновременно** по двум критериям:
1. По заработной плате (по возрастанию или убыванию).
2. По алфавиту (имя или фамилия).

### Решение

Использован компаратор с `thenComparing()` для многоуровневой сортировки:

```java
List<Employee> sortedEmployees = employees.stream()
    .sorted(Comparator
        .comparing(Employee::getSalary)
        .thenComparing(Employee::getName))
    .collect(Collectors.toList());

## 📦 Используемая библиотека

**com.skillbox.airport** — библиотека, предоставляющая данные об аэропорте.

### Основные классы:

| Класс | Описание |
|:------|:---------|
| `Airport` | Синглтон, содержащий список всех рейсов |
| `Flight` | Информация о рейсе (номер, тип, дата/время) |
| `Flight.Type` | Тип рейса: `ARRIVAL` (прилёт) или `DEPARTURE` (вылет) |
| `LocalDateTime` | Дата и время вылета/прилёта (Java Time API) |
