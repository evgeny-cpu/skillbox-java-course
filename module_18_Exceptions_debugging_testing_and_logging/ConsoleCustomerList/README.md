## 📖 Описание проекта

**ConsoleCustomerList** - консольное CRUD-приложение для управления списком клиентов. Программа позволяет добавлять, просматривать, обновлять и удалять данные клиентов с полной валидацией ввода и логированием всех операций.

### Функциональность
- ✅ Добавление новых клиентов
- ✅ Просмотр списка всех клиентов
- ✅ Обновление данных существующих клиентов
- ✅ Удаление клиентов
- ✅ Валидация телефонных номеров (11 цифр)
- ✅ Валидация email (наличие @ и точки)
- ✅ Логирование всех операций в файлы

# Задание 1: Обработка исключений

## 🎯 Цель задания

Научиться использовать механизм исключений (Exception handling) в Java для:
- Защиты от некорректной работы программы
- Обработки ошибок ввода пользователя
- Предотвращения преждевременного завершения программы

## 📋 Требования к защите

Программа должна корректно обрабатывать следующие ошибки ввода и **выбрасывать исключения**:

| № | Тип исключения | Что проверяется | Пример некорректного ввода |
|:--|:---------------|:----------------|:---------------------------|
| 1 | **InvalidCommandFormatException** | Количество элементов в команде (должно быть 4) | `add Иван` (не хватает параметров) |
| 2 | **InvalidPhoneNumberException** | Формат номера телефона (ровно 11 цифр) | `+123`, `890312345` (9 цифр) |
| 3 | **InvalidEmailException** | Наличие @ и точки в email | `usermail.ru`, `user@` |
| 4 | **DuplicateCustomerException** | Уникальность номера телефона | Попытка добавить существующий номер |
