# 🛡️ Обработка исключений в ConsoleCustomerList

**Задача:** Защитить консольное приложение от некорректного ввода и преждевременного завершения с помощью механизма исключений.

---

## 🎯 Цель задания

Научиться использовать механизм исключений (Exception handling) в Java для:
- Перехвата ошибок ввода пользователя
- Обработки некорректных форматов данных
- Предотвращения аварийного завершения программы

---

## 📋 Требования к защите

Программа должна корректно обрабатывать следующие ошибки ввода и **выбрасывать исключения**:

| № | Ошибка | Что проверять | Пример некорректного ввода |
|:--|:-------|:--------------|:---------------------------|
| 1 | **Неверный формат команды** | Количество элементов в команде | `add` (не хватает параметров)<br>`update 1` (не хватает полей) |
| 2 | **Неверный формат номера телефона** | Соответствие шаблону | `+123`, `abc`, `8(903)123-45` |
| 3 | **Неверный формат email** | Отсутствие @ и домена | `usermail.ru`, `user@`, `@mail.ru` |

---

## 🔧 Что нужно сделать

В проекте `ConsoleCustomerList` прописать все возможные варианты защиты от некорректной работы.

### Исходный проект

Программа представляет собой консольное CRUD-приложение для работы со списком клиентов.
Команды для управления:

| Команда | Формат | Описание |
|:--------|:-------|:----------|
| `add` | `add Имя Телефон Email` | Добавить нового клиента |
| `list` | `list` | Показать всех клиентов |
| `update` | `update ID Имя Телефон Email` | Обновить данные клиента |
| `delete` | `delete ID` | Удалить клиента |
| `exit` | `exit` | Выйти из программы |

---

## 💡 Реализация исключений

### 1️⃣ Создание собственных классов исключений

```java
// Исключение при неверном формате команды
class InvalidCommandFormatException extends Exception {
    public InvalidCommandFormatException(String message) {
        super(message);
    }
}

// Исключение при неверном формате телефона
class InvalidPhoneNumberException extends Exception {
    public InvalidPhoneNumberException(String message) {
        super(message);
    }
}

// Исключение при неверном формате email
class InvalidEmailException extends Exception {
    public InvalidEmailException(String message) {
        super(message);
    }
}
