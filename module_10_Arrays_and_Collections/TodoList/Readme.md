TodoList — консольное приложение для управления списком дел
📋 Описание проекта
Простое консольное приложение на Java для ведения списка дел. Пользователь взаимодействует с программой через текстовые команды, позволяющие добавлять, редактировать, удалять и просматривать задачи.

🚀 Функциональность
Приложение поддерживает следующие команды:

Команда	Описание	Пример использования
LIST	Выводит все дела с их порядковыми номерами	LIST
ADD	Добавляет дело в конец списка или на указанную позицию	ADD buy milk или ADD 2 buy milk
EDIT	Заменяет дело с указанным номером	EDIT 0 make a cup of tea
DELETE	Удаляет дело с указанным номером	DELETE 1
Особенности работы команд
ADD: если не указан индекс или указан несуществующий индекс, дело добавляется в конец списка

EDIT: при указании несуществующего индекса операция игнорируется

DELETE: при указании несуществующего индекса операция игнорируется

🛠️ Техническая реализация
Проект состоит из двух основных классов:

TodoList — отвечает за хранение и управление списком дел (бизнес-логика)

Main — обеспечивает взаимодействие с пользователем через консоль

📝 Пример работы
text
ADD buy milk
Добавлено дело "buy milk"

ADD learn java
Добавлено дело "learn java"

LIST
0 - buy milk
1 - learn java

EDIT 0 make a cup of tea
Дело "buy milk" заменено на "make a cup of tea"

DELETE 1
Дело "learn java" удалено

LIST
0 - make a cup of tea

DELETE 100
Дело с таким номером не существует
