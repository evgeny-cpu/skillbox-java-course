TodoList

Консольный менеджер списка дел с поддержкой команд.

Команды:
Команда	Формат	Описание
LIST	LIST	Показать все дела с номерами
ADD	ADD дело	Добавить дело в конец
ADD	ADD индекс дело	Вставить дело на позицию
EDIT	EDIT индекс новое_дело	Заменить дело
DELETE	DELETE индекс	Удалить дело
Пример работы:
text
ADD купить молоко
Добавлено дело "купить молоко"
LIST
0 - купить молоко
EDIT 0 купить хлеб
Дело "купить молоко" заменено на "купить хлеб"
