PhoneBook

Телефонная книга с двунаправленным поиском.

Архитектура: Использует HashMap<String, List> где:

Ключ: имя абонента

Значение: список телефонных номеров

Плюсы подхода: Быстрый поиск по имени

Возможность хранения нескольких номеров

Простая реализация

Минусы: Поиск по номеру требует перебора (O(n))

Необходимость синхронизации при добавлении

Команды: Имя - поиск по имени

Номер - поиск по номеру

LIST - все контакты

Пример:

Введите команду: Маша Найден: Маша - 79001234567, 79007654321 CoolNumbers Пакет: practice.CoolNumbers

Генерация и поиск "красивых" автомобильных номеров по различным коллекциям.

Формат номера: Формат: БУКВА ЦИФРА ЦИФРА ЦИФРА БУКВА БУКВА РЕГИОН

Буквы: А, В, Е, К, М, Н, О, Р, С, Т, У, Х

Регион: от 01 до 199

Пример: A111BC197, У777HC66

Структуры данных для поиска: ArrayList - прямой перебор

ArrayList (sorted) - бинарный поиск

HashSet - прямой доступ

TreeSet - сбалансированный поиск

Сравнение производительности:

Поиск перебором: номер найден, поиск занял 1542834нс Бинарный поиск: номер найден, поиск занял 34567нс Поиск в HashSet: номер найден, поиск занял 12345нс Поиск в TreeSet: номер найден, поиск занял 23456нс
