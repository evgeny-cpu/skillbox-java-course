ReverseArray

Класс ReverseArray содержит метод reverse(), который меняет порядок элементов массива на обратный.

Особенности:
Модифицирует исходный массив (работает с тем же объектом)

Поддерживает любые типы объектов

Пример:
java
String[] array = {"a", "b", "c", "d"};
ReverseArray.reverse(array);
// Результат: {"d", "c", "b", "a"}

TwoDimensionalArray

Создание двумерного массива с символами 'X' на диагоналях.

Метод:
getTwoDimensionalArray(int size) - возвращает квадратный массив размером size с X на обеих диагоналях.

Пример для size = 7:

X     X
 X   X
  X X
   X
  X X
 X   X
X     X

TodoList

Консольный менеджер списка дел с поддержкой команд.

Команды:
Команда	Формат	Описание
LIST	LIST	Показать все дела с номерами
ADD	ADD дело	Добавить дело в конец
ADD	ADD индекс дело	Вставить дело на позицию
EDIT	EDIT индекс новое_дело	Заменить дело
DELETE	DELETE индекс	Удалить дело

Пример работы:

ADD купить молоко
Добавлено дело "купить молоко"
LIST
0 - купить молоко
EDIT 0 купить хлеб
Дело "купить молоко" заменено на "купить хлеб"

PhoneBook

Телефонная книга с двунаправленным поиском.

Архитектура:
Использует HashMap<String, List<String>> где:

Ключ: имя абонента

Значение: список телефонных номеров

Плюсы подхода:
Быстрый поиск по имени

Возможность хранения нескольких номеров

Простая реализация

Минусы:
Поиск по номеру требует перебора (O(n))

Необходимость синхронизации при добавлении

Команды:
Имя - поиск по имени

Номер - поиск по номеру

LIST - все контакты

Пример:

Введите команду: Маша
Найден: Маша - 79001234567, 79007654321
CoolNumbers
Пакет: practice.CoolNumbers

Генерация и поиск "красивых" автомобильных номеров по различным коллекциям.

Формат номера:
Формат: БУКВА ЦИФРА ЦИФРА ЦИФРА БУКВА БУКВА РЕГИОН

Буквы: А, В, Е, К, М, Н, О, Р, С, Т, У, Х

Регион: от 01 до 199

Пример: A111BC197, У777HC66

Структуры данных для поиска:
ArrayList - прямой перебор

ArrayList (sorted) - бинарный поиск

HashSet - прямой доступ

TreeSet - сбалансированный поиск

Сравнение производительности:

Поиск перебором: номер найден, поиск занял 1542834нс
Бинарный поиск: номер найден, поиск занял 34567нс
Поиск в HashSet: номер найден, поиск занял 12345нс
Поиск в TreeSet: номер найден, поиск занял 23456нс
