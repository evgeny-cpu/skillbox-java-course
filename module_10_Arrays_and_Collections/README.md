## Массивы (Базовый уровень)

### Задание №1 - Реверс массива
Создание массива из мнемонической фразы "Каждый охотник желает знать, где сидит фазан" и изменение порядка элементов на обратный.

**Пример:**
```
Первоначальный массив: ["a", "b", "c", "d"]
Результат: ["d", "c", "b", "a"]
```

### Задание №2 - Температура пациентов
Генерация температур 30 пациентов в диапазоне 32-40°C и вычисление:
- Средней температуры по больнице
- Количества здоровых пациентов (36.2°C - 36.9°C)
- Вывод всех температур

**Пример вывода:**
```
Температуры пациентов: 36.7 38.9 34.7
Средняя температура: 36.76
Количество здоровых: 1
```

### Дополнительное задание - Крестик из X

## ArrayList - Список дел

Консольное приложение для управления списком дел с поддержкой команд:

- **LIST** - вывод всех дел с порядковыми номерами
- **ADD** [номер] [дело] - добавление дела (в конец или на указанную позицию)
- **EDIT** [номер] [новое название] - редактирование дела
- **DELETE** [номер] - удаление дела

**Примеры использования:**
```
ADD Купить продукты
ADD 4 Позвонить маме
EDIT 3 Новое название
DELETE 7
LIST
```

## TreeSet - Адресная книга

Программа для хранения и валидации email-адресов с использованием TreeSet.

**Возможности:**
- Автоматическая сортировка адресов
- Валидация формата email при добавлении
- Хранение только уникальных адресов

**Команды:**
- **ADD** email@domain.com - добавление нового адреса (с проверкой формата)
- **LIST** - вывод всех сохраненных адресов в отсортированном порядке

## HashMap - Телефонная книга

Телефонная книга с двунаправленным поиском на основе HashMap.

**Особенности:**
- Поиск по имени или номеру телефона
- Автоматическое определение типа ввода (имя/телефон) с помощью регулярных выражений
- Вывод контактов в алфавитном порядке

**Команды:**
- **Имя** - поиск/добавление контакта по имени
- **Телефон** - поиск/добавление контакта по номеру
- **LIST** - вывод всех контактов

**Реализация:**
В проекте используется две HashMap:
- `Map<String, String> phoneByName` - для поиска телефона по имени
- `Map<String, String> nameByPhone` - для поиска имени по телефону

*Плюсы: быстрый доступ O(1) в обоих направлениях*
*Минусы: дублирование данных, необходимость синхронизации при изменениях*

## Поиск и сортировка - Генератор номеров

Сравнение производительности различных методов поиска на примере генерации "красивых" автомобильных номеров.

### Генерация номеров
По правилам: XNNNYZR, где:
- X, Y, Z - буквы (различные)
- N - цифры
- R - регион (01-199)

Общее количество номеров: **более 2 миллионов**

### Сравниваемые методы поиска:
1. **Прямой перебор** в ArrayList
2. **Бинарный поиск** в отсортированном ArrayList
3. **Поиск в HashSet**
4. **Поиск в TreeSet**

### Измерение производительности
Использование `System.nanoTime()` для точного измерения времени поиска.

**Пример вывода:**
```
Поиск перебором: номер найден, поиск занял 1234567нс
Бинарный поиск: номер найден, поиск занял 12345нс
Поиск в HashSet: номер найден, поиск занял 567нс
Поиск в TreeSet: номер найден, поиск занял 890нс
```

### Результаты сравнения
- **Самый быстрый:** HashSet (O(1))
- **Самый медленный:** Прямой перебор в ArrayList (O(n))
