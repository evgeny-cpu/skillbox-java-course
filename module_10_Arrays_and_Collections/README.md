1. ReverseArray (Разворот массива)
   Цель: Научиться изменять порядок элементов в существующем массиве, не создавая новый.

Описание:
В классе ReverseArray реализован метод reverse(), который принимает массив строк и переставляет его элементы в обратном порядке. Важная особенность: метод не создаёт новый массив, а модифицирует тот, который был получен на вход.

Пример:

Входной массив: ["a", "b", "c", "d"]

Выходной массив (он же изменённый входной): ["d", "c", "b", "a"]

Техническая реализация:
Для разворота используется цикл, который идёт до середины массива и меняет местами первый элемент с последним, второй с предпоследним и так далее.

2. Hospital (Больничный отчёт)
   Цель: Сгенерировать данные и выполнить их статистический анализ.

Описание:
Класс Hospital моделирует сбор данных о температуре пациентов и формирует текстовый отчёт.

Генерация данных: Метод generatePatientsTemperatures() создаёт массив случайных значений температуры (тип float) для заданного количества пациентов. Температура генерируется в диапазоне от 32 до 40 градусов.

Формирование отчёта: Метод getReport() возвращает строку, которая содержит:

Все температуры пациентов, перечисленные через пробел.

Среднюю температуру по "больнице".

Количество здоровых пациентов (с температурой от 36.2 до 36.9 градусов включительно).

Пример вывода отчёта:

text
Температуры пациентов: 36.1 36.8 37.2 35.9 36.5 38.1 36.6
Средняя температура: 36.74
Количество здоровых: 4
3. TwoDimensionalArray (Диагонали массива)
   Цель: Закрепить навыки работы с двумерными массивами и вложенными циклами.

Описание:
Класс TwoDimensionalArray содержит метод getTwoDimensionalArray(int size), который создаёт и возвращает квадратный двумерный массив символов (char). Главная и побочная диагонали этого массива должны быть заполнены символом 'X', а все остальные ячейки — символом пробела ' '.

Визуализация для size = 7:

X     X
 X   X
  X X
   X
  X X
 X   X
X     X
(Примечание: пробелы были добавлены для наглядности, в реальном выводе их можно не отображать, они хранятся в ячейках массива).


4. TodoList (Консольный список дел)
   Цель: Разработать небольшое консольное приложение для управления списком задач, используя массив (или ArrayList) и обрабатывая пользовательский ввод.

Описание:
Программа представляет собой интерактивный список дел. Пользователь вводит команды в консоль, и программа их обрабатывает. Логика хранения и изменения списка вынесена в отдельный класс TodoList.

Класс TodoList:

Хранит список дел (например, в ArrayList<String>).

Реализует методы для добавления, удаления, редактирования и получения списка дел.

Класс Main:

Содержит бесконечный цикл для чтения команд пользователя.

Парсит введённую строку, определяет команду и её аргументы.

Вызывает соответствующие методы класса TodoList.

Выводит результат пользователю.

Доступные команды
LIST

Выводит на экран все дела с их порядковыми номерами.

Пример: LIST

Вывод: 0 - Купить молоко

ADD [индекс] дело

Добавляет новое дело. Если индекс не указан, дело добавляется в конец списка.

Если указан существующий индекс, дело вставляется на это место, а остальные сдвигаются.

Если указан несуществующий индекс, дело добавляется в конец.

Пример: ADD Выучить Java

Пример: ADD 1 Сходить в спортзал

EDIT [индекс] новое_дело

Заменяет дело под указанным номером на новый текст.

Если индекс не существует, программа сообщает об ошибке и ничего не меняет.

Пример: EDIT 0 Позвонить маме

DELETE [индекс]

Удаляет дело под указанным номером.

Если индекс не существует, программа сообщает об ошибке.

Пример: DELETE 2

Пример сессии в консоли

ADD Сделать зарядку
Добавлено дело "Сделать зарядку"

1 - Сделать зарядку
EDIT 0 Купить молоко
Дело "Купить хлеб" заменено на "Купить молоко"

LIST
