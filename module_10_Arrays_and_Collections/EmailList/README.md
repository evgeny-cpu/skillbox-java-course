EmailList

Хранилище email адресов с автоматической проверкой формата.

Особенности:
Автоматическая проверка валидности email

Хранение только уникальных адресов

Автоматическая сортировка при выводе

Команды:
ADD email@domain.com - добавить адрес

LIST - показать все адреса

Валидация:
Наличие @

Корректный домен

Отсутствие пробелов и спецсимволов
